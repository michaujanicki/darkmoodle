# Moodle PANS — Dark Mode

Rozszerzenie Chrome/Edge, które nakłada ciemny motyw tylko na `https://edu.pans.wloclawek.pl/`.

## Instalacja

1. Otwórz `chrome://extensions` (lub `edge://extensions`).
2. Włącz **Tryb programisty**.
3. Wybierz **Załaduj rozpakowane** i wskaż ten folder.
4. Otwórz Moodle. Ciemny motyw zostanie zastosowany automatycznie.

To rozszerzenie nie wysyła danych i nie wymaga logowania ani dodatkowych uprawnień.
